# Sliding Window

Two main variants of this pattern:

1. Fixed-Length Window
    - Window size is known.
    - Usually uses one pointer.
    - Common for problems like finding sums, averages, or maximum/minimum in subarrays of a fixed length.

2. Variable-Length Window
    - Window grows/shrinks based on constraints.
    - Uses two pointers.
    - Common for problems like longest/shortest substrings, subarrays with unique elements, or satisfying a condition.
